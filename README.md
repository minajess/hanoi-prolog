# Tower of Hanoi (Prolog)

An interactive Tower of Hanoi website. SWI-Prolog is the logic engine: it generates the optimal solution and validates every move.

## Run
1. Install SWI-Prolog (add it to PATH).
2. In this folder run: swipl server.pl
3. At the ?- prompt run: start.
4. Open http://localhost:8080
